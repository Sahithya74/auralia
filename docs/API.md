# Anbu REST API

Base path: `/api`. JSON in and out unless noted. All responses carry `Cache-Control: no-store`.

**Authentication.** Protected endpoints need `Authorization: Bearer <accessToken>` (15-minute JWT). The refresh token is an `httpOnly`, `SameSite=Strict` cookie (`anbu_rt`, path `/api/auth`). Cookie-authenticated endpoints (`/auth/refresh`, `/auth/logout`) also require the header `X-Anbu-Client: web` (CSRF protection).

**Errors** always look like:

```json
{ "error": { "code": "VALIDATION_ERROR", "message": "Some details are missing or invalid.", "fields": ["email"] } }
```

Submitted values are never echoed back. Resources owned by someone else return `404`, exactly like resources that don't exist.

**Rate limits** (per IP unless noted): login 10 failed attempts / 15 min · register 10 / hour · password reset 5 / hour · refresh 60 / 15 min · chat 20 / min per user · everything else 600 / 15 min per user. Exceeding a limit returns `429 RATE_LIMITED`.

## Health

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/health` | — | `200 {status:"ok", database:"ok", ai:{provider, mock}, languages:[...]}`, or `503` with `status:"degraded"` if the database is unreachable |

## Authentication

| Method | Path | Body | Result |
|---|---|---|---|
| POST | `/auth/register` | `{name, email, password (8–128), preferredLanguage?}` | `201 {accessToken, expiresIn, user}` + refresh cookie. `409 EMAIL_IN_USE` |
| POST | `/auth/login` | `{email, password}` | `200 {accessToken, expiresIn, user}` + cookie. `401 INVALID_CREDENTIALS` (same for unknown email) |
| POST | `/auth/refresh` | — (cookie) | Rotates the refresh token. `401 REFRESH_INVALID / REFRESH_EXPIRED / REFRESH_REUSED / REFRESH_RACE` |
| POST | `/auth/logout` | — (cookie) | `204`; revokes the whole token family |
| POST | `/auth/forgot-password` | `{email}` | Always `200` with the same message (no account enumeration) |
| POST | `/auth/reset-password` | `{token, password}` | `200`; single-use token, 30 min; signs out all sessions. `400 RESET_INVALID` |

Refresh tokens are stored only as SHA-256 hashes. Presenting an already-rotated token more than 20 s after rotation is treated as theft and revokes every session in that family.

## User and preferences

| Method | Path | Body | Result |
|---|---|---|---|
| GET | `/users/me` | — | `{user}` |
| PATCH | `/users/me` | any of `{name, preferredLanguage, interactionMode: VOICE\|TEXT\|BOTH, onboardingCompleted: true}` | `{user}` |
| PATCH | `/users/me/preferences` | any of `{responseStyle: LISTEN\|SOLUTIONS\|BALANCED, codeMixing, voiceOutputEnabled, voiceRate (0.5–1.5), voiceGender: FEMALE\|MALE, voiceInputReview, captionsEnabled, reducedMotion, textSize: md\|lg\|xl, highContrast, dailyPromptEnabled}` | `{user}` |

`user.persistence` = `{mode, transcripts, memories}` tells the client exactly what may be stored. History and analytics consent are changed only through `/privacy/settings`.

## Chat

| Method | Path | Description |
|---|---|---|
| POST | `/chat/stream` | Streams a reply as **Server-Sent Events** |
| POST | `/chat` | Same, returns JSON when complete |
| POST | `/chat/reflect` | Optional post-conversation summary / next steps / memory suggestions |
| POST | `/voice/speech` | `{text, language, gender?: FEMALE\|MALE, allowSlow?}` → Anbu's reply as streamed 16-bit PCM (`audio/L16; rate=24000`). 503 `VOICE_BUSY` when no natural voice is available (the app then uses the device voice); 501 when natural voice is off. `allowSlow` also tries the slower backup voice model, for devices with no voice of their own |

Request body for `/chat/stream` and `/chat`:

```json
{
  "requestId": "uuid generated by the client (duplicate submissions get 409 DUPLICATE_REQUEST)",
  "conversationId": "optional - only meaningful when history is stored",
  "language": "en | ta | hi | ml | kn | te",
  "messages": [{ "role": "user | assistant", "content": "..." }],
  "mood": "optional: carrying | tired | peaceful | need_to_talk",
  "replacesLast": "optional: true when she corrected her last (mis-heard) message"
}
```

The client sends the recent conversation (the server uses the last 24 turns); the last message must be from the user and at most 4,000 characters. At most 2 concurrent streams per user (`429 CHAT_BUSY`).

SSE events:

| Event | Data |
|---|---|
| `meta` | `{safety: {level: none\|concern\|urgent, categories, resources:[{id, phone}]}, ai: {mock}}` — sent first |
| `delta` | `{text}` — a fragment of the reply |
| `done` | `{conversationId \| null, persisted, staticFallback, timing: {prepareMs, firstTokenMs, totalMs}}` |
| `error` | `{code: AI_BUSY\|AI_TIMEOUT\|AI_NETWORK\|AI_UNAVAILABLE\|AI_REFUSAL\|AI_ERROR, retryable, partial}` |

A `: keep-alive` comment is sent every 15 s. If the client disconnects, the model request is aborted and **nothing is stored**. Exchanges are stored only when the user's privacy settings allow transcripts.

`/chat/reflect` body: `{kind: "summary" | "next_step" | "memory_suggestions", language, messages}` → `{text}` or `{suggestions: [{content, category, kind, sensitive}]}`. Memory suggestions are never saved automatically and require Personal memory (`403 PERSISTENCE_BLOCKED` otherwise).

## Conversation history

Only available when `memoryMode = PERSONAL` and history is on.

| Method | Path | Result |
|---|---|---|
| GET | `/conversations` | `{conversations: [{id, title, language, createdAt, updatedAt, messageCount}]}` (latest 50). `403 HISTORY_DISABLED` |
| GET | `/conversations/:id` | `{conversation: {..., messages: [{id, role, content, language, createdAt}]}}` |
| DELETE | `/conversations/:id` | `204` |
| DELETE | `/conversations` | `{deleted}` |

## Memories

| Method | Path | Body | Result |
|---|---|---|---|
| GET | `/memories` | — | `{memories: [...]}` |
| POST | `/memories` | `{content (≤500), category?, kind?: STATED\|INTERPRETATION, sensitive?}` | `201 {memory}`. `403 PERSISTENCE_BLOCKED` unless Personal memory |
| PATCH | `/memories/:id` | any of `{content, category, enabled, sensitive}` | `{memory}` |
| DELETE | `/memories/:id` | — | `204` |
| DELETE | `/memories` | — | `{deleted}` |

Categories: `PREFERENCE, PEOPLE, ROUTINE, WELLBEING, GOAL, OTHER`. Limit: 200 memories per user.

## Privacy and account

| Method | Path | Body | Result |
|---|---|---|---|
| GET | `/privacy/settings` | — | `{memoryMode, historyEnabled, analyticsConsent, persistence, stored: {conversations, memories}}` |
| PATCH | `/privacy/settings` | any of `{memoryMode, historyEnabled, analyticsConsent}` + `confirmDeletion?` | Updated settings. If the change would delete stored data and `confirmDeletion` isn't `true`: `409 CONFIRM_DELETION` with `details: {conversations, memories}` |
| POST | `/account/export` | — | JSON download of account, preferences, memories and stored conversations (no password hash or tokens) |
| DELETE | `/account` | `{password}` | `204`; deletes the user and everything linked to it. `401 INVALID_PASSWORD` |
